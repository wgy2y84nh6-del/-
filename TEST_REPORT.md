# Точечное обновление — 1 ноября 2026

Это обновление существующей игры. Графика, палитра, сцены, положение и масштаб
паразитов, музыка, анимации, навигация и окончания не пересоздавались.

Изменены только игровые `scripts/main.gd` и `scripts/game_state.gd`:

* Удалён пункт главного меню «Звук». Остальные четыре кнопки центрированы
  и равномерно расположены в прежних границах блока.
* Удалены кнопка «Мыть» и её клавиша 2. Остались «Кормить», «Гладить», «Спать».
  Кнопка «Гладить» перемещена между кормлением и сном; остальные панели
  и поле игры не перемещались. Надпись — только «Гладить»; удержание и
  три сердечка работают по-прежнему.
* Интервал еды: **7,0 с вместо 6,0 с (+16,7%)**. По одному шарику в мозгу
  и кишечнике, мгновенное исчезновение, +1 за сбор; кормление стоит 3.
* Базовый расход сытости: **0,56 п./с вместо 0,50 (+12%)**. Прежнее увеличение
  сложности по числу паразитов сохранено: 0,56 / 0,6832 / 0,8064 п./с.
* Чистота продолжает снижаться прежним темпом, но не ниже **50%**.
  Это единственное необходимое исключение для удалённого ухода: без него
  старое сохранение с низкой чистотой могло навсегда заблокировать яйцо.
  Остальные темпы потребностей, условия размножения и таймеры **50/20/40**
  не менялись. Кнопок или новых действий ухода не добавлено.

**Ввод и интерфейс:** проверены мышь, настоящие touch-события через браузер,
удержание и отпускание, отмена поглаживания при переключении, три сердечка,

заголовки и позиции панелей проверены структурно и просмотром скриншотов.
Левосторонние подписи из референса остаются выровненными слева.

**Графика:** все 24 исходных PNG сверены побайтно с приложенным ZIP.
Фон и паразит используют один масштаб. Положение в органах зафиксировано
в координатах исходных референсов: (112,42), (112,42), (112,78).
Кадры имеют одну опору, без масштабирования при переключении. Пары обычной
анимации и сна наблюдались в браузере; блеск яйца проверен при прохождении.
Позиции после переселения проверены тестом. Скриншоты органов и меню

Попиксельное совпадение с UI-фотографиями не заявляется.

**Звук:** измерен реальный Web Audio output через AnalyserNode. После нажатия
пользователя есть ненулевой сигнал; регуляторы независимы; совместное
обнуление даёт практически нулевой сигнал; возврат громкости возвращает звук.

нажатий. Три стадии музыки плавно сменяются. Органных записей нет: все WAV
созданы собственным синтезатором без внешних сэмплов, лицензия CC0 приложена.

## Границы проверки

* **Safari на macOS/iOS здесь не запускался.** Выбран совместимый однопоточный
  WebGL 2 / WebAssembly экспорт; фактическая проверка Safari остаётся невыполненной.
  Проверка сенсорного ввода выполнялась в Chrome/Chromium/Edge с эмуляцией касаний,
  а не на физических телефонах.
* Самодостаточный HTML проверен **по HTTP** со всеми ресурсами внутри файла.
  Установленный управляемый браузер блокирует `file://` политикой администратора,
  поэтому запуск двойным щелчком здесь не проверен. Обычный Web ZIP требует HTTP(S).
* Нативный запуск / импорт проверен на Linux в Godot 4.6.3. Другие версии редактора,
  macOS и Windows отдельно не проверены.
* Веб-версия **не опубликована на внешнем хостинге**. Самодостаточный HTML и Web ZIP
  готовы для размещения; публичной игровой ссылки нет.

## Повторить проверки

```sh
godot --headless --editor --import --quit
godot --headless --script tests/test_game.gd
godot --headless --script tests/test_ui.gd
godot --headless --export-release Web build/web/index.html
python3 tools/serve.py build/web --port 8765
```

При установленном Playwright: `node tests/browser.cjs` — полное прохождение;
`node tests/browser_smoke.cjs` — функциональные проверки, ввод и звук.
Тесты не меняют таймеры и не управляют игрой через `window.__homeState`:
это лишь наблюдаемый снимок, игровые действия выполняются через GUI.
