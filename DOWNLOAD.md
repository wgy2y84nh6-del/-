# Скачать «Ты мой дом · Паразит-тамагочи»

Сохранён существующий проект Godot 4.6.3 из облачного окружения.

## Полный исходный проект

Откройте [ветку с проектом](https://github.com/wgy2y84nh6-del/-/tree/codex/save-parasite-tamagotchi) и нажмите **Code → Download ZIP**.

Или [скачайте ZIP ветки напрямую](https://github.com/wgy2y84nh6-del/-/archive/refs/heads/codex/save-parasite-tamagotchi.zip).

После распаковки импортируйте корневой `project.godot` в Godot **4.6.3 stable**, дождитесь импорта ресурсов и нажмите **F5**.

## Готовые файлы

- [Исходный ZIP Godot](https://github.com/wgy2y84nh6-del/-/raw/refs/heads/codex/save-parasite-tamagotchi/downloads/You-Are-My-Home-Godot.zip) — существующий архив без изменений.
- [ZIP браузерной версии](https://github.com/wgy2y84nh6-del/-/raw/refs/heads/codex/save-parasite-tamagotchi/downloads/You-Are-My-Home-Web.zip) — существующий Web Export без изменений.
- `downloads/You-Are-My-Home.html` — ранее созданная версия в одном HTML-файле.

Для браузерной версии распакуйте весь Web ZIP в одну папку. На Windows запустите в этой папке `py serve.py . --open`; на macOS/Linux — `python3 serve.py . --open`. Нужен Python 3. Браузерную версию запускайте через локальный сервер, как описано в её README.

## Что сохранено

В корне находятся все 123 файла существующего исходного проекта: `project.godot`, сцена, скрипты и UID, все 24 оригинальных PNG, музыка и эффекты, шрифты и лицензии, настройки импорта и экспорта, инструменты, тесты, отчёты и документация.

`SOURCE_FILES.sha256` содержит контрольные суммы всех исходных файлов. `downloads/SHA256.json` содержит ранее созданные контрольные суммы обоих ZIP и отдельного HTML. Копии сверены с существующим проектом; ZIP проверены на целостность.

Кэш `.godot`, служебные данные Git, локальные сохранения, временные файлы и установленные инструменты окружения в исходники не включены. Готовый браузерный экспорт сохранён в Web ZIP.

Игра не пересоздавалась. Существующие файлы облачного окружения не изменены. Ранее выполненные проверки игры описаны в исходном `TEST_REPORT.md`; при сохранении повторно проверялись комплектность и целостность файлов.
