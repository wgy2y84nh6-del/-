# Ты мой дом · Паразит-тамагочи

Новая законченная игра на **Godot 4.6.3 / GDScript**. Compatibility / WebGL 2,
однопоточный Web Export без расширений, CDN и внешних запросов во время игры.

## Запуск исходного проекта

1. Распакуйте архив исходников.
2. В Godot **4.6.3 stable** нажмите «Импорт» и выберите `project.godot`.
3. Дождитесь импорта PNG, WAV и шрифтов, затем нажмите **F5**.

Все игровые пути относительные `res://`. Основная сцена — `scenes/Main.tscn`.
Панели и элементы управления создаются скриптом `scripts/main.gd`.
Редактируйте поведение в `game_state.gd`, композицию в `art.gd`.
Другие версии Godot 4 отдельно не проверялись; рекомендуется 4.6.3.

## Запуск готовой браузерной версии

Отдельный **You-Are-My-Home.html** содержит ту же игру вместе с движком и
всеми ресурсами в одном файле. Его запуск проверен по HTTP без дополнительных
ресурсов. Открытие через `file://` зависит от политики браузера и здесь не
проверялось: установленный управляемый браузер блокирует этот протокол.

Распакуйте отдельный ZIP веб-версии. В этой папке выполните:

```sh
python3 serve.py . --open
```

На Windows можно использовать `py serve.py . --open`.
Скрипт сам откроет браузер. Если Python отсутствует, разместите **все** файлы
архива на статическом **HTTPS-хостинге**. MIME для `.wasm` должен быть
`application/wasm`. Открытие HTML через `file://` не подходит для WebAssembly.
SharedArrayBuffer и COOP/COEP-заголовки не требуются: потоки выключены.
Для локального сервера подходит HTTP localhost; для публикации используйте
HTTPS, необходимый браузерным AudioWorklet. Нужны WebGL 2, WebAssembly,
включённый JavaScript. Музыка запускается после
первого нажатия пользователя, как требуют браузеры.

## Игра

* Пух живёт в сердце. Нажимайте на шарики в мозгу и кишечнике: каждый даёт
  ровно **1 еду**, мгновенно исчезает и не собирается повторно.
  Раз в **6 секунд** оба слота снова могут содержать по одному шарику.
  Несобранные шарики не складываются и не теряются от навигации.
* Выберите питомца в блоке «Твоя семья». Кормление стоит **3 еды** и
  восстанавливает сытость; мытьё — чистоту; сон — энергию.
* Удерживайте «Гладить» или самого паразита: довольство растёт, над ним
  появляются три сердечка. Отпускание, уход указателя, смена экрана или
  потеря фокуса сразу прекращают действие.
* Ухудшение потребностей продолжается во всех органах и на экране человека.
  Главная опасность — голод. Сон переключается кнопкой «Спать/Разбудить».
* Только Пух откладывает яйца каждые **50 секунд**, если все четыре его
  потребности не ниже 50%. Если условия не выполнены, он ждёт улучшения.
  Яйцо вылупляется через **20 секунд**. Максимум — три паразита с учётом яйца.
* Лилу появляется в сердце. Выберите его и нажмите «Переселить → мозг».
  Так же переселите Ростика в кишечник после следующего вылупления.
  Пух остаётся в сердце. Без переселения новорождённые не перекрывают его.
* После появления третьего паразита начинается **40-секундный** финал.
  Если все трое выживут, человек умирает — хорошая концовка для паразитов.
  Гибель любого паразита даёт плохую концовку. Оба рисунка взяты из архива.
* Пауза останавливает симуляцию. Окна настроек и справки также ставят игру
  на паузу и возвращают прежнее состояние после закрытия.
* Сохранение автоматическое каждые две секунды и при важных событиях;
  в браузере — синхронная копия в localStorage и файловая копия в IndexedDB.
  После перезагрузки нажмите «Продолжить».
  Офлайн-время не вычитается. Настройки музыки и эффектов сохраняются отдельно.
  Приватный режим или очистка данных сайта могут удалить сохранение.

**Клавиатура:** 1 — кормить, 2 — мыть, 4 — сон, пробел — пауза,
H — человек, Q/W/E — сердце/мозг/кишечник, Esc — закрыть окно или пауза.
Мышь и касания используют одни и те же игровые действия.

## Экспорт и проверки

Установите официальные **Export Templates 4.6.3** через редактор Godot.
Затем в корне проекта:

```sh
godot --headless --editor --import --quit
godot --headless --script tests/test_game.gd
godot --headless --script tests/test_ui.gd
godot --headless --export-release Web build/web/index.html
python3 tools/serve.py build/web --open
```

`export_presets.cfg` включён. Каталог `build/web` уже создан в исходном ZIP.
Для автоматизации браузера нужен Node.js и Playwright; сам проект от них
не зависит. `tests/browser.cjs` проходит игру реальными кликами без ускорения.
Наблюдение `window.__homeState` доступно только для чтения снимка состояния;
игровых команд или изменения времени через него нет.

Итоговые выполненные проверки и ограничения перечислены в `TEST_REPORT.md`.
Геометрия референсов — в `ART_PLACEMENT.md`.

## Ресурсы и права

В `assets/original` находятся все 24 предоставленных PNG с исходными именами
и без изменений. Права на них остаются у их правообладателей; перед публикацией
используйте имеющееся у вас разрешение. Дополнительные рисунки не добавлялись.

Шрифты DejaVu сопровождаются своей свободной лицензией. Три музыкальные темы
и 11 коротких эффектов синтезированы для игры; `assets/audio/LICENSE.txt`
предоставляет их по CC0. Генератор — `tools/make_audio.py`.
Записей тела, сердцебиения, дыхания или звуков органов нет. При смене стадии
человека темы перекрёстно затухают за 2.5 секунды, становясь тревожнее.
